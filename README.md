# JcuzziPark
Service to define the best area to move the Jacuzzi Park into.

## 🚀 New Alternative UI Available!

We've created a completely new alternative user interface with a modern, dark theme and advanced visualization features. 

**Two UI Options:**
- **Original UI**: Clean, professional layout with light theme
- **Alternative UI**: Modern dark theme with glass morphism effects and enhanced interactivity

**How to Switch:**
1. Start the application: `npm run dev`
2. Click the "🚀 Try Alternative UI" button in the top-right corner
3. Use the back arrow in the alternative UI to return to the original

## Features Comparison

| Feature | Original UI | Alternative UI |
|---------|-------------|----------------|
| Theme | Light & minimal | Dark & futuristic |
| Layout | 3-column grid | Sidebar + full-screen |
| Map Style | Clean points | Glowing effects |
| Interactions | Static | Animated & dynamic |
| Navigation | Left sidebar | Top navigation bar |

See [ALTERNATIVE_UI_DOCS.md](./ALTERNATIVE_UI_DOCS.md) for detailed documentation.
